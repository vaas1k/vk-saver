# VK Saver

Программа для Windows, которая делает архив данных ВКонтакте пригодным для чтения без интернета.

ВКонтакте по запросу выдаёт архив ваших данных: набор страниц с перепиской и фотографиями. Сами фотографии и голосовые сообщения в нём лежат не файлами, а ссылками на серверы ВКонтакте, и со временем эти ссылки перестают открываться. VK Saver скачивает файлы по этим ссылкам, кладёт их рядом со страницами и переписывает страницы так, чтобы они открывали копии на диске.

Программа не входит в ваш аккаунт, не спрашивает логин, пароль или токен и ничего не отправляет в сеть: она только скачивает файлы по ссылкам из архива. Всё остаётся на вашем компьютере.

## Как пользоваться

1. Запросите архив своих данных во ВКонтакте, как описано на странице https://vk.ru/faq18145?lang=ru, отметив сообщения и фотографии. Когда архив будет готов, ВКонтакте пришлёт ссылку на ZIP-файл. Распаковывать его не обязательно.
2. Скачайте программу со страницы релизов https://github.com/vaas1k/vk-saver/releases (Windows 10/11, 64 и 32 бит): `vk-saver-setup.exe` (установщик, 64 бит) или `vk-saver-setup-x86.exe` (32 бит). Без установки: `vk-saver.exe` (64 бит) или `vk-saver-x86.exe` (32 бит). Не уверены? Берите вариант для 64 бит. Файлы не подписаны, поэтому при первом запуске Windows покажет предупреждение: нажмите "Подробнее", затем "Выполнить в любом случае".
3. Запустите программу и нажмите "Выбрать ZIP" (или "Выбрать папку", если архив уже распакован).
4. На экране "Что найдено" видно, сколько файлов нашлось и сколько места они займут. В списке "Чаты" отметьте нужные: переключатель "Все / Личные / Беседы" фильтрует список, кнопка "Выделить всё" отмечает или снимает показанные чаты.
5. Нажмите "Скачать". Скачивание можно остановить и продолжить позже кнопкой "Докачать".
6. На экране "Готово" нажмите "Открыть архив в браузере". Фотографии и голосовые сообщения теперь открываются с диска. Там, где файл уже удалён во ВКонтакте, на странице написано "источник недоступен".

Видео и документы программа не скачивает: их список со ссылками лежит в отчёте `vk-saver/report.html` внутри папки архива.

## Как вернуть всё назад

Исходные страницы архива сохраняются без изменений в папке `vk-saver/originals/`. Кнопка "Вернуть исходные страницы" на экране "Готово" возвращает их на место; скачанные файлы при этом остаются на диске.
